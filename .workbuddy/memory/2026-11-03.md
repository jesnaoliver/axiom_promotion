## 修复的 6 个缺陷

### 1. 【严重】截图脱敏长段落逃逸（根因修复）
- **现象**：已发布配图 `shot_dashboard.jpg` 明文暴露方向性判断 ——
  "华鑫策略认为A股处于震荡筑底阶段，建议先维持防御型哑铃配置…再转向小微盘、低位主题及科技等高弹性资产"
- **根因**：`source/screenshot.py` 的 `JS_MASK_RISKY_FALLBACK` 有
  `t.length > 240` 直接 `return` 的长度上限。
  AXIOM 日报「宏观与海外速览」正文是一个 300~500 字的 `<p>`，
  超限 → 整段跳过 → 方向性判断原样进图。
  且词表缺 `震荡/筑底/防御/哑铃/转向/反弹/预期`，bullet 要点行也没被命中。
- **修法**：新增 `JS_MASK_RISKY_SENTENCE` —— **文本节点层按句读切分**，
  逐句判定（命中 `RISKY_KEYWORDS` 或 `ATTRIBUTION_RE` 署名）→ 整句替换为
  「（该句涉及方向性判断，已隐去）」，连续多段合并为「（该段 N 处…）」。
  长度无关，长段落不再逃逸。
- **为什么不用模糊**：模糊会触发「糊过头」回退，而回退路径当时**恰恰没跑
  方向性遮蔽** —— 等于为好看反而漏得更彻底。且 OCR 对模糊字形仍有残留风险。

### 2. 【严重】「糊过头」回退路径漏遮蔽（比原问题更危险）
- **现象**：回退后 dashboard 右栏「本周周报」15 条研报原文**全部清晰可见**
  （"市场出现超跌反弹交易窗口…当前更适合低估值为基、政策受益和防御方向"）。
  原因：右栏遮蔽逻辑只写在 `shot_dashboard` 内部，回退时被整个丢掉。
- **修法**：
  - 右栏遮蔽抽成 `_mask_reading_column()`，通过 `_shot_guarded(on_fallback=...)` 在回退时同样执行。
  - 回退路径补跑 `_mask_risky_sentences()` + `JS_MASK_DIRECTION`。
  - `shot_dashboard` 改走 `_shot_guarded`（原先是裸 `_shot`，无回退兜底）。

### 3. 【严重】发布器无去重守卫
- **现象**：`2026-11-03` 已在 11-02 17:43 提前发布过一篇
  （`AX-2026-11-01-conf`），而当天再跑 dry-run 产出的第 0 篇
  **标题完全相同** → 会被平台判重复内容/刷量。
- **修法**：
  - `publish/publisher.py` 新增 `_published_index()`，扫描 `logs/` 索引
    已发布 topic_id + 标题；`publish()` 在**发布动作前**硬拦截（stage=dedup）。
  - `scheduler.build_from_axiom`：`--index` 默认改为 `None` = **自动挑选
    第一篇未发布过的**（topic_id + 标题双重去重）。
  - `scheduler._published_today()`：同一自然日只发一篇，已有成功记录则跳过，
    写 `logs/<date>_axiom_skipped.json`。

### 4. 弹窗研报标题泄漏
- 「陈果：科技反弹的逻辑」在详情弹窗顶部清晰可见（券商署名 + 方向性判断）。
  旧规则只抓【《】开头，抓不到「人名：观点」格式。
- 修法：新增 `JS_MASK_DIALOG_TITLE`（匹配 `^[一-龥]{2,4}[:：]\s*\S`）。

## 词表设计原则（重要，勿轻易放宽）
只收**构成"行情判断 / 操作建议"语义**的词；
纯描述性宏观词（预期/主导/传导/持续/延续/谨慎）**刻意不收** ——
收了会把整段宏观速览糊掉，图片失去产品演示价值。
实测：泄漏句命中 11 词 + 署名；描述性宏观句零误伤。
