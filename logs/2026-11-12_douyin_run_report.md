```python

```

两条都失效了：
1. `"private" in cls` —— 角标 class 在**子 span** 上，且卡片容器 class
   变成了 `video-card-new-disabled-*`（含 "disabled"，不含 "private"）；
2. `"私密" in txt` —— 文案已改成「作品仅自己可见 / 限制自己可见」，
   **不再出现「私密」二字**。

### 本次修复的两个实现细节（回归测试抓出来的，勿回退）

1. **`set_visibility` 的分组定位**：不能用「找含『谁可以看』的最小容器」
   —— 编辑器里那个容器同时含**发布时间**的 radio，会找不到目标。
   正解：**从 radio 自身向上逐级找含「谁可以看』的祖先**（最多 8 层），
   再用「label 文本 == mode」+ value 双重匹配。
2. **回读校验不能用 `closest('div,section,form')`**：
   「谁可以看」是 radio 的**兄弟** label，不是祖先文本 →
   `closest` 恒返回 null → 误判「没点上」→ 白白放弃保存。

## 六、沿用的既有做法（勿改动）

- 真实发布必须 `run_in_background=true`（前台 120s 超时 SIGTERM 会丢日志）
- 发布前先跑 `_probe_check_title.py` 只读核查，避免重复发布
- 当日已发过会被当日守卫拦下；AXIOM 登录失败不要重试超过一次
- 命令 `scheduler.py --source douyin`，**不要**加 `--index`
- 探针退出码：找到目标标题时**主动 exit 非 0**（语义是「不要重跑发布」），
  判读要看 stdout 最后一行判定语，不要只看 exit code
