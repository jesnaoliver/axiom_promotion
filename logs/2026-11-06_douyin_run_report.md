## 二、⚠️ 本次修掉一个「假成功」bug

### 现象
日志写 `✅ AI 内容标识已勾选`，但**编辑器里根本没有这个选项**。

### 根因
`publish/douyin/publisher.py` 的 `declare_ai_content()` 兜底 label 是裸串 `"AI生成"`，配合
`"AI生成" in t and len(t) < 30` 的**模糊匹配**：

今天这篇正文恰好有一句「看任何 **AI生成** 的东西时」→ 命中的是**正文段落 `<p>`**，
于是对它执行 `el.click()`（在编辑器里点了正文），日志却记成「已勾选」。

**为什么 11-04/05 是「未找到」而 11-06 是「已勾选」？**
纯粹取决于当天正文里是否碰巧出现「AI生成」三个字。同一段代码两种表现 ——
所以前三次的告警和这次的「成功」都不能作为结论，必须靠 DOM 实测。

### DOM 实测结论
编辑器整页截图显示，「发布设置」区只有「谁可以看」「发布时间」；
全部 checkbox 仅 5 个：公开 / 好友可见 / 仅自己可见 / 立即发布 / 定时发布 ——
**0 个 AI 相关选项**。页面上唯一带「AI」字样的是头图区的「AI 配图 / AI换图」，
那是 AI 配图功能，不是内容标识。

### 修复内容
1. 移除裸 `"AI生成"`，改用 `AI_DECL_LABELS`（含有AI生成内容 / 含AI生成内容 / AI生成内容 /
   内容由AI生成 / AI生成声明 / AI声明 / 内容声明）
2. 要求命中元素**自身文本 == label**（必须是纯标签，不能是含该词的句子或容器）
3. 新增 `_in_body_editor()` / `_in_preview()`，**排除正文编辑器与右侧手机预览区**

### 回归验证（已跑通）
```
declare_ai_content() 返回: False      ← 预期（编辑器无此选项）
正文长度 514 → 514（未改动）✅
光标位置 '投资复盘' → '投资复盘'（未移动）✅
```
确认不再误点正文。

> ⚠️ **注意**：修完后日志会**重新变成**「⚠️ 未找到 AI 内容标识选项」—— 这是**正确行为**，不是回归。
> 平台事实：抖音文章编辑器内确实无「含有AI生成内容」选项，若平台强制要求，只能人工处理。
